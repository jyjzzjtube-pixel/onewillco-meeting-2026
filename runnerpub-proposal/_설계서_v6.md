### 1-5. 도시 실루엣 텍스처 (다크 면 필수 · 순색 네이비 금지)

IR 14장에 순색 네이비 면은 0장이다. 사진 자산이 없으므로 벡터로 생성한다.

```
function skyline(s, x, y, w, h) {   // 다크 면 하단에 깔림
  const seed = [0.42,0.68,0.31,0.85,0.55,0.24,0.72,0.48,0.90,0.36,
                0.61,0.29,0.78,0.44,0.66,0.33,0.82,0.51,0.27,0.70];
  const bw = w / seed.length;
  seed.forEach((v,i)=> rect(s,{x:x+bw*i, y:y+h-h*v, w:bw*0.86, h:h*v}, NAVYTEX));
}
```
- 색 `NAVYTEX #33456B` 단색(네이비 대비 명도 +10% 수준). 투명도 미사용 → PPT 호환 안전.
- 배치: 전면 다크 장은 하단 1.6in 폭 전체, 분할 다크 컬럼은 하단 1.1in, 표지는 하단 1.9in.

## 5. 그리드 변경 지시 (`grid.js` BANDS 교체)

`anchor` 밴드 신설, `brow` 축소, `rule`을 최상단으로 이동, `bandRule` 폐지. **합계 6.840 정확히 일치.**

```js
const BANDS = [
  ['topRule',  0.012],   // ★ 최상단 풀폭 괘선 (기존 rule 을 위로 이동)
  ['topGap',   0.150],
  ['brow',     0.300],   // 좌: 챕터번호 13pt / 우: 내일사장 로고
  ['browGap',  0.100],
  ['anchor',   0.460],   // ★ 신설 — 영문 챕터 앵커 32pt (챕터 첫 장만)
  ['head',     0.560],   // 국문 명사형 헤드 26pt 1줄
  ['lead',     0.440],   // 리드문 13pt 최대 2줄
  ['leadGap',  0.260],
  ['body',     3.128],   // ★ 본문
  ['bodyGap',  0.140],
  ['note',     0.200],   // 각주 8.5pt
  ['noteGap',  0.120],
  ['band',     0.520],   // ★ 결론 밴드 (문장형/칩형/수치형 3분기)
  ['footGap',  0.180],
  ['footRule', 0.010],
  ['foot',     0.260],
];
// 합 = 0.012+0.150+0.300+0.100+0.460+0.560+0.440+0.260+3.128
//     +0.140+0.200+0.120+0.520+0.180+0.010+0.260 = 6.840 ✓
```

**절대 y 좌표(검산용, SAFE.y = 0.36)**

| 밴드 | y | h | b |
|---|---|---|---|
| topRule | 0.360 | 0.012 | 0.372 |
| brow | 0.522 | 0.300 | 0.822 |
| anchor | 0.922 | 0.460 | 1.382 |
| head | 1.382 | 0.560 | 1.942 |
| lead | 1.942 | 0.440 | 2.382 |
| body | 2.642 | 3.128 | 5.770 |
| note | 5.910 | 0.200 | 6.110 |
| band | 6.230 | 0.520 | 6.750 |
| footRule | 6.930 | 0.010 | 6.940 |

**파생 영역 (grid.js 하단에 추가)**

```js
// 앵커 없는 장: anchor+head 를 병합해 국문 헤드 2줄 허용 (24pt)
Y.headFull = { y: Y.anchor.y, h: Y.head.b - Y.anchor.y, b: Y.head.b };   // 0.922 / 1.020
// 각주 없는 장: body+bodyGap+note 흡수
Y.bodyFull = { y: Y.body.y, h: Y.note.b - Y.body.y, b: Y.note.b };       // 2.642 / 3.468
// 결론 밴드 없는 장: band 까지 흡수
Y.bodyMax  = { y: Y.body.y, h: Y.band.b - Y.body.y, b: Y.band.b };       // 2.642 / 4.108
// 풀블리드 결론 밴드 (검사 예외 · 화면 좌우·하단 끝까지)
const BLEED = { x: 0, y: 6.130, w: W, h: H - 6.130 };                    // 13.333 × 1.370
```

**좌우 명암분할 사용법** (P.02·P.11·P.14 — grid를 깨지 않는다)

```js
// 1) 배경 도형을 먼저 전면 블리드로 깐다 (at() 검사 밖의 순수 장식)
rect(s, {x:0, y:0, w:W*0.46, h:H}, NAVY2);   // 또는 우측 분할
skyline(s, 0, H-1.1, W*0.46, 1.1);
// 2) 그 위에 기존 span() 컬럼으로 텍스트를 얹는다 — 좌표 체계 그대로 유지
const L = span(0,6), R = span(6,6);
```
분할 경계 x는 **반드시 컬럼 거터 중앙**에 둔다. 6/6 분할 → x = `colX(6) - GUT/2` = 6.1265. 4/8 분할 → `colX(4) - GUT/2` = 4.1385.

**풀블리드 결론 밴드 사용 시 주의** — 밴드가 `foot`까지 덮으므로 해당 장의 푸터는 `INK_ON`·`MUTED`(다크 팔레트)로 렌더한다. `frame(s, no, ch, dark)`에 `bleedBand` 플래그를 추가해 푸터 색을 분기시킬 것.
