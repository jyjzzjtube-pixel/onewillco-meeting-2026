# ChatGPT 이미지 생성·편집 프롬프트 지시서 (v2)
> 러너펍 가맹영업 제안서용 — **레퍼런스 서칭·추출 → 업로드 → 상세 프롬프트 → 크롭** 워크플로우
> 기준 캔버스: 제안서 슬라이드 **1240px 폭**, 다크 퍼플 테마 — 좌표는 좌측 상단 (0,0) 기준

## 작업 원칙 (모든 이미지 공통)

1. **레퍼런스 먼저**: 아래 표의 레퍼런스 이미지를 먼저 확보(저장소 `assets/` 또는 지정 URL에서 다운로드)한 뒤, **대상 이미지와 함께 업로드**하고 프롬프트를 입력한다. 레퍼런스 없이 텍스트만으로 생성하지 않는다.
2. **업로드 시 역할 지정**: 프롬프트 첫 줄에 반드시 "첫 번째 이미지는 스타일 레퍼런스, 두 번째 이미지는 편집 대상"처럼 각 이미지의 역할을 명시한다.
3. **크롭 지시 포함**: 생성/편집 후 반드시 크롭 요청까지 한 번에 지시한다 (비율 + 기준점). ChatGPT가 크롭을 못 하면 결과물을 받아 제안서 CSS(`object-fit:cover; object-position`)로 크롭한다 — 각 항목에 두 방식 모두 적어둠.
4. 모든 결과물에 **텍스트 삽입 금지** (한글 깨짐 방지 — 텍스트는 제안서에서 직접 얹음).
5. 브랜드 컬러 고정: 메인 `#7C5CFC`, 딥 `#1A1040`, 포인트 골드 `#F5B93D`, 배경 `#0D0820`.
6. 수정은 "같은 구도 유지하고 ○○만 바꿔줘"로 부분 수정 (전체 재생성 금지).
7. 저장: PNG → `runnerpub-proposal/assets/gen_번호.png`

## 이미지 1 — 표지 배경 무드 강화 (선택)

**① 레퍼런스 서칭·추출**
- 레퍼런스 A: `assets/card.png` (토끼 카드 심볼 — 브랜드 모티프)
- 레퍼런스 B: `assets/ranking.png` (브랜드 보라 톤 기준)

**② 업로드 후 프롬프트 (복사용)**
```
첫 번째 이미지(카드 심볼)는 브랜드 모티프 레퍼런스, 두 번째 이미지(앱 화면)는 컬러 톤 레퍼런스야.
이 두 레퍼런스의 보라색 톤(#7C5CFC)과 카드 모티프를 반영해서 2480x1280 가로형 표지 배경을 만들어줘.
- 배경: 딥 바이올렛(#241457)에서 거의 검정(#0D0820)으로 떨어지는 대각선 그라데이션
- 우측 1/3 영역에만 레퍼런스와 같은 토끼 문양 플레잉 카드 2장과 포커칩이 보랏빛 림라이트를 받으며
  떠 있는 시네마틱 3D 연출, 투명도 40% 느낌으로 배경에 녹아들게
- 좌측 2/3는 텍스트용으로 어둡고 깨끗하게, 미세한 필름 그레인
- 텍스트는 절대 넣지 마
완성되면 16:9 비율로, 우측 카드가 잘리지 않게 우측 기준으로 크롭해줘.
```

**③ 크롭·배치**
- ChatGPT 크롭: 16:9, 우측 기준 / 대체 CSS: `object-fit:cover; object-position:right center`
- 배치: 표지 섹션 배경 전체 (0,0 ~ 1240×640). 텍스트는 x=72, y=180부터 좌측 정렬.

## 이미지 2 — 홀덤 라운지 매장 무드컷 (필수 · 실사풍)

**① 레퍼런스 서칭·추출**
- 레퍼런스 A: 러너펍 공식 인스타그램/블로그에서 실제 매장 사진 1~2장 서칭해 저장 (검색어: "러너펍 방이점", "러너펍 매장 인테리어")
- 레퍼런스 B: `assets/ranking.png` (브랜드 보라 톤)
- 실제 매장 사진을 못 구하면 레퍼런스 B만 업로드하고 진행

**② 업로드 후 프롬프트 (복사용)**
```
첫 번째 이미지는 실제 매장 분위기 레퍼런스, 두 번째 이미지는 브랜드 컬러(#7C5CFC) 레퍼런스야.
이 분위기를 바탕으로 2400x1000 와이드 실사풍 홀덤 라운지 인테리어를 만들어줘.
- 그린 펠트 포커 테이블 2~3개, 보라색 네온 간접조명, 다크 톤 프리미엄 인테리어
- 사람은 실루엣 3~4명만, 얼굴이 식별되지 않게
- 현금·술병 클로즈업 같은 요소는 넣지 말고 '건전한 보드게임 라운지' 무드로
- 좌우 가장자리로 갈수록 어두워지는 비네팅 (텍스트 오버레이용), 텍스트 없음
완성되면 상하를 잘라 12:5 와이드 비율로, 테이블이 중앙에 오게 크롭해줘.
```

**③ 크롭·배치**
- ChatGPT 크롭: 12:5, 중앙 기준 / 대체 CSS: `height:420px; object-fit:cover; object-position:center 60%`
- 배치: '브랜드 이해' 슬라이드와 '제안 내용' 슬라이드 사이에 풀폭 배너 섹션으로 삽입 (1240×420). 저장 후 요청 주시면 제가 섹션에 바로 넣어드립니다.

## 이미지 3 — 앱 목업 배경 정리 (선택)

**① 레퍼런스 서칭·추출**: 대상 이미지 = `assets/ranking.png` (원본 검정 배경)

**② 업로드 후 프롬프트 (복사용)**
```
업로드한 이미지가 편집 대상이야. 검정 배경을 완전히 제거해 투명 배경 PNG로 만들어줘.
휴대폰 2대와 자연스러운 그림자만 남기고, 가장자리를 깨끗하게 따줘. 다른 요소 추가 금지.
완성되면 여백을 최소화해서 휴대폰 2대가 꽉 차게 크롭해줘.
```

**③ 크롭·배치**: 현재 제안서는 다크 테마라 원본을 그대로 쓰는 게 더 자연스러움. 밝은 인쇄용 버전을 만들 때만 진행.

## 이미지 4 — 엠버서더/이벤트 콜라주 (선택)

**① 레퍼런스 서칭·추출**
- 대상: 러너펍 공식 사이트 엠버서더 이미지 6장 다운로드
  `https://runnerpub.com/images/ambassador/1.png` ~ `6.jpg` (2번·6번은 .jpg)
- 레퍼런스: `assets/ambassador.png`

**② 업로드 후 프롬프트 (복사용)**
```
업로드한 이미지들은 콜라주 대상이야 (실존 인물이므로 얼굴 변형·재생성 절대 금지, 원본 그대로 배치만).
2000x800 가로 캔버스에 폴라로이드 카드 스타일로 6장을 비스듬히 겹쳐 배치해줘.
- 배경은 다크 퍼플(#1A1040) 단색, 각 사진에 흰색 테두리와 부드러운 그림자
- 사진 간 회전 각도는 -6도~+6도 사이로 자연스럽게
- 텍스트 없음
완성되면 5:2 비율로 중앙 기준 크롭해줘.
```

**③ 크롭·배치**
- ChatGPT 크롭: 5:2 중앙 / 대체 CSS: `object-fit:cover`
- 배치: '브랜드 이해' 슬라이드 하단 (x=72, y≈820, 폭 1096). ※ 실존 인물 사진이므로 **제안서 외부 배포 전 본사 사용 허락 필요** — 1차 미팅용 내부 자료로만.

## 제안서에 이미 코드로 반영되어 ChatGPT가 필요 없는 것

- 파트너십/수수료 3단계 플로우 → HTML/CSS 제작 완료 (수수료 슬라이드)
- 전국 확장 지도 → SVG 제작 완료 (로드맵 슬라이드, 서울·경기/광역시/전국 3단계)
- 표지 카드 모티프 → `assets/card.png` + CSS 글로우로 반영 완료
