# ChatGPT 이미지 생성·편집 프롬프트 지시서
> 러너펍 가맹영업 제안서용 이미지 제작 가이드
> 사용법: 각 항목의 ①업로드할 파일 → ②ChatGPT에 붙여넣을 프롬프트(그대로 복사) → ③결과물 배치 좌표 순서로 이행
> 기준 캔버스: 제안서 슬라이드 **1920×1080px (16:9)** — 좌표는 좌측 상단 (0,0) 기준

---

## 이미지 1 — 표지(커버) 배경

**① 업로드**: `assets/logo.png` (러너펍 화이트 로고)

**② 프롬프트 (복사용)**:
```
업로드한 로고를 그대로 유지한 채, 1920x1080 가로형 프레젠테이션 표지 배경을 만들어줘.
- 배경: 딥 바이올렛(#5B3DF5)에서 다크 퍼플(#2A1B6E)로 흐르는 대각선 그라데이션 (좌측 상단→우측 하단)
- 우측 하단 영역(x 1300~1920, y 500~1080)에 홀덤 포커 카드 2장(스페이드 A, 하트 K)과 포커칩 3~4개가 은은한 보랏빛 조명을 받으며 떠 있는 고급스러운 3D 일러스트, 투명도 60% 느낌으로 배경에 녹아들게
- 좌측 절반(x 0~960)은 텍스트가 올라갈 수 있게 장식 없이 어둡고 깨끗하게
- 업로드한 화이트 로고를 좌측 상단 x=100, y=80 위치에 가로 400px 크기로 배치
- 미세한 노이즈 텍스처, 시네마틱하고 프리미엄한 라운지 분위기, 텍스트는 절대 넣지 마
```

**③ 배치**: 제안서 1페이지 전체 배경 (0,0 ~ 1920,1080). 제목 텍스트는 x=100, y=430부터 좌측 정렬로 위에 얹음.

## 이미지 2 — 파트너십(제휴 구조) 비주얼

**① 업로드**: 없음 (순수 생성)

**② 프롬프트 (복사용)**:
```
1200x800 이미지를 만들어줘. 비즈니스 파트너십을 상징하는 미니멀 3D 일러스트.
- 좌측에 보라색(#5B3DF5) 빌딩 아이콘(가맹본부), 우측에 골드색 확성기/영업 아이콘(영업 에이전시)
- 두 아이콘이 중앙에서 악수 모양 또는 연결된 링으로 이어지는 구성, 중앙 연결부는 화이트 글로우
- 배경은 아주 연한 라벤더(#F3F0FF) 단색, 그림자 부드럽게
- 플랫 + 소프트 3D 혼합 스타일, 텍스트 없이
```

**③ 배치**: '협업 구조' 페이지 우측 영역 x=1150, y=250 위치에 가로 640px로 축소 배치. 좌측(x 100~1050)은 텍스트 영역.

## 이미지 3 — 전국 확장 로드맵(지도) 비주얼

**① 업로드**: 없음 (순수 생성)

**② 프롬프트 (복사용)**:
```
1000x1200 세로형 이미지. 대한민국 지도를 미니멀한 도트 패턴(보라색 #5B3DF5 점들)으로 표현해줘.
- 배경 화이트, 지도 도트는 보라 계열
- 서울·경기 위치에 큰 글로우 포인트 1개, 부산/대구/광주/대전 위치에 중간 글로우 포인트,
  그 외 지역에 작은 핀 6~7개를 흩어놓아 "전국으로 확장 중" 느낌
- 각 포인트에서 위로 은은한 빛기둥, 텍스트·지명 라벨은 넣지 마
- 깔끔한 인포그래픽 스타일
```

**③ 배치**: '영업 확장 전략' 페이지 우측 x=1250, y=140 위치, 세로 800px로 배치. 좌측에 권역별 영업 계획 텍스트.

## 이미지 4 — 홀덤펍 매장 무드컷 (시장 소개 페이지)

**① 업로드**: 없음 (순수 생성)

**② 프롬프트 (복사용)**:
```
1920x700 와이드 이미지. 고급스러운 홀덤 라운지 인테리어 실사풍 렌더링.
- 그린 펠트 포커 테이블 2~3개, 보라색 무드 조명(#5B3DF5 네온 간접조명), 다크 인테리어
- 사람은 실루엣으로만 3~4명, 얼굴 안 보이게
- 술과 도박 요소(현금, 술병 클로즈업)는 넣지 말고 '보드게임 카페처럼 건전한 라운지' 분위기
- 우측으로 갈수록 어두워지는 그라데이션 (텍스트 오버레이용), 텍스트 없음
```

**③ 배치**: '시장 현황' 페이지 상단 배너 (0,0 ~ 1920,700). 우측 x=1100~1850, y=150~550 영역에 화이트 텍스트 오버레이.

## 이미지 5 — 러너러너 앱 목업 편집 (배경 제거·재배치)

**① 업로드**: `assets/ranking.png` (앱 목업 원본 — 검정 배경)

**② 프롬프트 (복사용)**:
```

휴대폰 2대와 그림자는 그대로 유지하고, 가장자리를 깨끗하게 따줘. 다른 요소는 추가하지 마.
```

**③ 배치**: '러너러너 플랫폼' 페이지 우측 x=1200, y=120 위치에 세로 850px로 배치. 원본 보라 화면과 제안서 배경이 자연스럽게 연결됨.

## 이미지 6 — 성공보수 구조 다이어그램 배경

**① 업로드**: 없음 (순수 생성)

**② 프롬프트 (복사용)**:
```
1600x500 가로 배너. "성과가 없으면 비용도 없다"를 상징하는 미니멀 그래픽.
- 좌측에서 우측으로 이어지는 3단계 스텝 (리드 발굴 → 상담·계약 → 성공보수) 느낌의
  추상적인 화살표 흐름, 보라(#5B3DF5)→골드(#F5B93D) 그라데이션
- 마지막 3번째 스텝에만 골드 코인/체크 아이콘으로 포인트
- 배경 화이트, 플랫 인포그래픽 스타일, 텍스트는 절대 넣지 마 (텍스트는 제안서에서 직접 얹음)
```

**③ 배치**: '수수료 구조' 페이지 중앙 x=160, y=420 위치. 각 스텝 위 y=380 라인에 단계명 텍스트, 아래 y=760 라인에 설명 텍스트를 좌표 맞춰 얹음 (스텝 중심 x ≈ 400 / 880 / 1360).

## 공통 지시사항

1. 모든 생성 이미지에 **텍스트 삽입 금지** (한글 텍스트 깨짐 방지 — 텍스트는 제안서 편집 시 직접 입력)
2. 브랜드 컬러 고정: 메인 `#5B3DF5`(바이올렛), 서브 `#2A1B6E`(다크퍼플), 포인트 `#F5B93D`(골드), 배경 `#F3F0FF`(라벤더)
3. 결과물이 마음에 안 들면: "같은 구도 유지하고 ○○만 바꿔줘" 식으로 부분 수정 요청 (전체 재생성 금지 — 톤 틀어짐 방지)
4. 최종 저장: PNG, 다운로드 후 `runnerpub-proposal/assets/gen_이미지번호.png`로 저장
5. 실존 인물·연예인·타 브랜드 로고가 나오면 즉시 재생성 요청 ("인물 얼굴 제거해줘")
