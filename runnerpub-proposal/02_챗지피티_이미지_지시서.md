# 챗지피티 이미지 생성·편집 지시서 — 러너펍 제안서 v5

> 제안서에 넣을 이미지를 챗지피티에서 만드는 절차입니다.
> **레퍼런스 검색 → 업로드 → 프롬프트 → 크롭 → 슬라이드 좌표에 삽입** 순서로 진행합니다.
> 슬라이드 좌표는 `grid.js` 체계 기준이며, PPT에서 그림 서식 → 크기·위치에 그대로 입력하면 됩니다.

---

## 0. 공통 규칙

**색 지정 (반드시 프롬프트에 넣을 것)**

| 이름 | HEX | 용도 |
|---|---|---|
| 네이비 | `#16233D` | 어두운 배경 |
| 브랜드 블루 | `#2C68F3` | 강조 |
| 라이트 블루 | `#7FA8FF` | 어두운 배경 위 강조 |
| 페이퍼 | `#F2F4F8` | 밝은 배경 |
| 잉크 | `#1D2C47` | 밝은 배경 위 글자 |

**금지 사항 — 프롬프트 끝에 붙일 것**
```
No text, no letters, no numbers, no watermark, no logo.
No people's faces. No stock-photo look. No drop shadows. No gradients on the background.
Flat vector line illustration only, uniform stroke weight.
```

**해상도**: 정사각 생성 후 크롭. 최종 삽입 해상도는 **가로 1인치당 300px** 이상.

## 1. 표지 이미지 — 이미 완료 (교체 시에만 사용)

현재 IR 자료의 일러스트를 추출해 사용 중입니다. 교체하실 경우에만 아래를 쓰십시오.

**① 레퍼런스 검색**
구글 이미지에서 아래 키워드로 3~5장 저장
```
flat line illustration desk top view documents keyboard
isometric line art business analysis outline
```

**② 업로드**
저장한 레퍼런스를 챗지피티 대화창에 **모두 첨부**하고 아래 문장을 먼저 보냅니다.
```
첨부한 이미지들의 선 굵기, 여백 처리, 시점(위에서 내려다보는 각도)을 참고 자료로만 쓰고,
그대로 베끼지는 마세요. 아래 지시대로 새로 그려 주세요.
```

**③ 프롬프트**
```
Flat vector line illustration, top-down view of a desk.
Elements: a document with bar-chart blocks, a hand pointing at the document,
a second hand typing on a keyboard, a pen lying diagonally at the top.
Stroke color #F4F6FA, uniform 6px stroke, no fill except one shape filled with #2C68F3 at 40% opacity.
Background fully transparent.
Composition: vertical, elements stacked top to bottom, generous margin on all sides.
Aspect ratio 1:2.2 (tall).
No text, no letters, no numbers, no watermark, no logo. No faces. Flat line only.
```

**④ 크롭**
생성물을 내려받아 이미지 편집기에서
- 캔버스 비율 **1 : 2.19** (예: 1060 × 2320 px)
- 상하좌우 여백을 잉크 기준 **각 40px**로 균등하게 맞춤
- 배경 투명 PNG로 저장 → 파일명 `illust_cover.png`

**⑤ 슬라이드 삽입 좌표 (P.01 표지)**

| 항목 | 값 |
|---|---|
| 가로 위치 | **11.05 in** (좌측 기준) |
| 세로 위치 | **2.28 in** (상단 기준) |
| 너비 | **1.06 in** |
| 높이 | **2.32 in** |

## 2. 신규 제작 대상 ①  P.11 진단 — 홀덤펍 매장 컷

현재 P.11 우측 하단은 텍스트 카드입니다. 매장 분위기 컷을 넣으면 설득력이 올라갑니다.

**① 레퍼런스 검색**
```
holdem pub interior dim lighting poker table
card lounge bar counter warm light interior
```
러너펍 공식 인스타그램·홈페이지의 매장 사진도 함께 저장하십시오.

**② 업로드 후 첫 메시지**
```
첨부한 사진들은 러너펍 실제 매장과 유사한 홀덤펍 공간입니다.
이 공간의 구조(포커 테이블 배치, 조명 위치, 바 카운터)만 참고해서
사진이 아니라 선 일러스트로 다시 그려 주세요. 특정 매장을 식별할 수 있으면 안 됩니다.
```

**③ 프롬프트**
```
Flat vector line illustration of a holdem pub interior, wide horizontal composition.
Elements: one oval poker table in the center-left with chairs around it,
a bar counter on the right, three pendant lights above the table.
Stroke color #1D2C47, uniform 5px stroke. One accent: the pendant light glow filled #2C68F3 at 25% opacity.
Background fully transparent. Empty room, no people.
Aspect ratio 16:9.
No text, no letters, no numbers, no watermark, no logo. No faces. Flat line only, no photo realism.
```

**④ 크롭**
- 비율 **16 : 9** (예: 1440 × 810 px)
- 좌우 여백 각 5%, 상하 여백 각 8%
- 투명 PNG → `p11_pub.png`

**⑤ 슬라이드 삽입 좌표 (P.11)**
현재 「내일사장이 담당하는 구간이 정확히 여기입니다」 카드 자리를 위로 올리고 그 아래 배치합니다.

| 항목 | 값 |
|---|---|
| 가로 위치 | **7.78 in** |
| 세로 위치 | **4.92 in** |
| 너비 | **4.80 in** |
| 높이 | **2.70 in** |

※ 넣으실 경우 알려 주시면 그 자리를 비우도록 레이아웃을 다시 잡아 드리겠습니다.

## 3. 신규 제작 대상 ②  P.09 업무 — 3단계 흐름 아이콘

현재 P.09의 3개 컬럼은 번호만 있습니다. 각 컬럼 상단에 아이콘을 넣으면 구분이 빨라집니다.

**① 레퍼런스 검색**
```
outline icon set minimal line 3px consistent stroke
business process icon line art megaphone map-pin handshake
```

**② 업로드 후 첫 메시지**
```
첨부한 아이콘들의 선 굵기와 단순화 수준만 참고하세요.
아래 세 가지를 같은 스타일, 같은 크기, 같은 선 굵기로 한 장에 나란히 그려 주세요.
```

**③ 프롬프트**
```
Three flat line icons in a single row on one transparent canvas, evenly spaced.
Icon 1: a handshake (represents franchise sales agency).
Icon 2: a megaphone with three short motion lines (represents marketing).
Icon 3: a map pin over a simplified storefront outline (represents store development).
Stroke color #2C68F3, uniform 8px stroke, rounded caps, no fill.
Each icon fits inside its own 300x300 area. Background fully transparent.
Aspect ratio 3:1.
No text, no letters, no numbers, no watermark, no logo. Flat line only.
```

**④ 크롭 — 개별 분리**
한 장으로 받은 뒤 **아이콘 3개를 각각 정사각으로 잘라** 3개 파일로 저장합니다.
- 각 파일 비율 **1 : 1** (예: 300 × 300 px)
- 아이콘 잉크가 캔버스의 **78%**를 차지하도록 여백 조정
- 투명 PNG → `p09_icon1.png` / `p09_icon2.png` / `p09_icon3.png`

**⑤ 슬라이드 삽입 좌표 (P.09) — 3개 각각**

| 아이콘 | 가로 위치 | 세로 위치 | 너비 | 높이 |
|---|---|---|---|---|
| 1 가맹영업대행 | **0.75 in** | **2.55 in** | 0.40 in | 0.40 in |
| 2 창업 마케팅 | **4.70 in** | **2.55 in** | 0.40 in | 0.40 in |
| 3 점포개발 | **8.64 in** | **2.55 in** | 0.40 in | 0.40 in |

## 4. 신규 제작 대상 ③  P.05 팀 — 배경 텍스처

팀 페이지가 텍스트만이라 무겁습니다. 아주 옅은 배경 텍스처를 깔면 밀도가 잡힙니다.

**① 레퍼런스 검색**
```
subtle blueprint grid background dark navy minimal
architectural grid line pattern low contrast
```

**② 프롬프트** (업로드 불필요)
```
Seamless subtle grid pattern for a dark presentation background.
Base color #16233D. Grid lines #2B3A56 at 1px, spacing 40px, plus thicker lines every 200px.
Very low contrast, the pattern must be barely visible.
No vignette, no gradient, no noise, no text, no logo.
Aspect ratio 16:9.
```

**③ 크롭**
- 비율 **16 : 9**, 4000 × 2250 px
- 그대로 저장 → `p05_bg.png` (투명 불필요, 불투명 PNG)

| 세로 위치 | **0 in** |

## 5. 편집이 필요한 경우 (기존 이미지 수정)

챗지피티에 **원본을 업로드**하고 아래 형식으로 요청하십시오.

```
첨부한 이미지에서 [바꿀 대상]만 [바꿀 내용]으로 수정하고,
나머지 구도·선 굵기·색은 그대로 두세요.
배경은 투명하게 유지하고, 캔버스 크기는 원본과 동일하게 유지하세요.
```

**예시 — 선 색만 바꾸기**
```
첨부한 일러스트에서 선 색만 #F4F6FA 로 바꾸고,
파란 면은 #2C68F3 40% 불투명도로 유지하세요.
구도, 선 굵기, 캔버스 크기는 원본 그대로 두세요. 배경은 투명입니다.
```

## 6. 삽입 후 확인 절차 (필수)

이미지를 넣은 뒤 **반드시** 아래를 확인하십시오. 좌표 체계가 깨지면 나머지 배치가 전부 틀어집니다.

1. PPT에서 그림 선택 → **서식 → 크기** 에서 위 표의 너비·높이가 정확히 입력됐는지 확인
2. **위치** 에서 가로·세로 값이 표와 일치하는지 확인 (기준은 항상 **왼쪽 위 모서리**)
3. 그림이 **본문 영역**(세로 2.47 in ~ 6.03 in)을 벗어나지 않는지 확인
4. 그림이 **결산 밴드**(세로 6.44 in 아래)를 침범하지 않는지 확인
5. 넣은 뒤 저에게 파일을 주시면 좌표 검사기(`grid.js`)로 전 페이지를 다시 검증해 드립니다
