# 러너펍 제안서 v9 — 내일사장 IR 어법 그대로

배경을 화이트 위주로, 그라데이션을 넣고, 전개·텍스트·내용을 IR 정석대로 맞춘 판이다.
본사가동 3관점(텍스트 · 전개 · 어필)이 IR 14장을 정독해 뽑은 어법 규칙을 그대로 적용했다.

## 1. IR 에서 뽑은 문장 규칙 (근거 인용 포함)

| 규칙 | IR 근거 |
|---|---|
| 헤드라인은 명사형 종결. 서술어·마침표 금지 | ir06 `실 매출 분석을 통한 피해사례 방지` / ir09 `유사시장 비교 및 전망` |
| 헤드 구조는 [수식절 + 조사 + 명사], 8~30자, 최대 2행 | ir11 `소상공인 고객 확보를 위한 전략적 제휴 및 마케팅 활동의확장` |
| 리드문은 14장 중 2장에만 | ir04 · ir05 앱 사용 안내 2장 |
| 소제목·행라벨은 2~10자 명사 | ir03 `이해관계자 / 거래 목적 / 문제 내용` |
| 표 셀은 길이 무관 전부 명사 종결 | ir09 41자 셀도 종결이 `확보` |
| 결론 띠는 명사형, 마침표 없음, 앞 원인 → 뒤 결과 | ir03 `…불확실한 정보취득으로 적자 운영 및 조기 폐업 초래` |
| 숫자는 `약 + 값 + 단위`, 비율·범주·기준시점은 괄호 | ir08 `합계 250만명 (56%)` |
| 각주는 `출처 :` 또는 `※` 로 시작해 명사형 종결 | ir08 `출처 : 통계청(2023)` |
| 인물 약력은 `현]` `전]` 접두 필수 | ir13 `전] 이삭토스트 총괄사업부장 (COO)` |
| 초대형 수치는 Scale-up 한 장에만 | ir10 `5,000+ / 90,000+ / 30,000+` |

## 2. v8 → v9 변경

| 항목 | v8 | v9 |
|---|---|---|
| 다크 면적 평균 | 21.8% | **1.7%** (표지 하단 띠만) |
| 좌측 네이비 사이드바 | 7장 | **0장** — 옅은 그라데이션 틴트면으로 대체 |
| 헤드라인 | 서술형 `~습니다` 11장 | **전 장 명사형 2행** |
| 리드문 | 14장 | **2장** (08 운영 화면 안내 · 15 행동 요청) |
| 결론 띠 | 8장 | **2장** (02 · 10 챕터 종료) |
| 초대형 수치 | 12장에 분산 | **04 한 장에 집중** (4분할) |
| 노란 형광 | 8장 | **0건** — IR 14장에 형광 0건 |
| 러닝 푸터 | 15장 | **삭제** — 우하단 회색 쪽번호만 |
| 각주 | 페이지 하단 몰아쓰기 | **숫자 바로 아래** · 필수 3건 반영 |
| 그라데이션 | 없음 | **7종** — 지면 · 패널 · 막대 · 결론 띠 · 표지 |

## 3. 신설 · 삭제

**신설**
- P.07 전략적 제휴 현황 8칸 — v8 에서 로고만 눕혀 놓았던 것을 IR ir11 어법의 설명 카드로
- P.08 STEP 4 정보공개서 D-day 화면 — 코드로 그려 추가
- P.13 전자계약 잠금 흐름 4단 도식 — 2열 표 반복을 끊는다
- P.15 슬로건 `내일부터 내 일이 사장이 되는 플랫폼` — 브리프 §1 확정 문구, v8 에 없었다

**삭제**
- 좌측 네이비 사이드바 7장 · 하단 파란 띠 6장 · 띠 안 흰 칩 나열 · 노란 형광 전량
- 페이지 하단 우측 대형 수치 슬롯 7개 (`0 원` 4회 등) — IR 에 이 슬롯 자체가 없다
- P.15 담당 · 연락처 · 이메일 서명란 — IR 엔딩에 없는 요소

**교정**
- P.13 헤드 `준법 영업을 사람이 아니라 시스템이 막습니다` → 막아야 할 대상이 위법 영업인데
  준법 영업을 막는다고 쓰여 있었다. `사람이 아닌 시스템 기반의 준법 통제` 로 교체
- P.12 `※ 러너펍 공개 가맹 안내 기준 시뮬레이션 · 실제 조건은 본사 정책에 따름` — 브리프 §5
  필수 각주가 v8 에서 누락돼 있었다. 최우선 교정
