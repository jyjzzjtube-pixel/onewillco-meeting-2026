# 러너펍 제안서 v8 — 내일사장 IR 문법 이식

v7 이 어두운 면을 너무 많이 써서 색이 죽었다는 지적을 받고, 내일사장 IR 14장을
픽셀 단위로 다시 측색해 색·면 구성을 IR 문법으로 맞춘 판이다. 내용은 v7 과 같다.

## 1. IR 실측 (ir01~ir14 · 8단위 양자화 후 전 페이지 집계)

| 색 | 값 | 점유율 | 쓰임 |
|---|---|---|---|
| 지면 | `#F8F8F8` | 47.2% | 배경의 절반 — IR 은 흰 지면이 주다 |
| 네이비 | `#203858` 계열 | 약 15% | 좌측 세로 밴드 · 표지 |
| 회색 틴트 | `#F0F0F0` | 5.8% | 소제목 띠 |
| 파랑 | `#2868F0` | 강조 | 수치 · 칩 · 결론 띠 |
| 연파랑 | `#A8C0F8` | 보조 | 막대 · 테두리 |
| 파랑 틴트 | `#E8F0F8` / `#E0E8F8` | 표·카드 배경 |

핵심: **IR 의 다크 면적은 15%다.** v7 은 39%였다. 색이 죽은 원인이 이것이다.

## 2. v7 → v8 변경

| 항목 | v7 | v8 |
|---|---|---|
| 다크 면적 평균 | 39.3% | **21.8%** |
| 챕터 표지 4장 | 순색 네이비 전면 | **좌측 다크 세로 밴드 4.10in + 흰 지면** |
| P.03 · P.12 | 우측 다크 분할 | **파랑 틴트 패널** (`#E7EFFA` / `#F4F7FD`) |
| 결론 밴드 문장형·칩형 | 네이비 풀블리드 | **파랑 `#2868F0` 순색 풀블리드** — 흰 글씨 · 노랑 강조 |
| 칩형 밴드 칩 | 네이비2 칩 | **흰 칩 + 파란 글씨** |
| 제휴 로고월 | 그레이스케일 (다크 위) | **원색 복귀** (흰 카드 위) |
| 표 | 괘선만 | **홀짝 행 틴트 + 회색 소제목 띠** |
| 빨강 | 상승률에만 | **PROBLEM 태그 · 경로 종착칩 · 과장정보 열 · 성공보수 금액**까지 확대 |
| 좌우 분할 폭 | 5.66in (42%) | 4.90in (37%) |

## 3. 신설 골격

- `sectionBar()` — 회색 틴트 소제목 띠 + 파란 좌측 액센트. IR 의 섹션 헤더 어법
- `tagChip()` — 작은 회색 기간·날짜 칩
- `runsOnBlue()` — 파란 띠 위 런(기본 흰색 · 대괄호는 형광 노랑)
- `splitPanel()` — 항상 y 0→7.5in 풀블리드. 인셋 카드 금지

## 4. 검사기 변경

순색 풀블리드 면 비율(25~35%) 규격을 **다크 면적 비율**로 교체했다.
IR 실측 15%를 기준선으로 두고 허용 12~25%. 면을 몇 장 칠했는지가 아니라
화면에서 어두운 면이 실제로 몇 %인지를 0.06in 격자로 재는 방식이다.
파란 면(휘도 0.17)은 다크로 세지 않는다.
