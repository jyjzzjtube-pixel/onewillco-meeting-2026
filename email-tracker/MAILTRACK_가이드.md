# Mailtrack로 Gmail 수신확인 (가장 쉬운 방법 · 코딩 X)

> 보낸메일함에서 상대가 메일을 **열었는지 / 언제 열었는지** 체크마크로 확인.
> PC 크롬에서 확장 설치만 하면 됨. (clasp·코드 불필요)

## 1) 설치
1. **PC 크롬** 실행 → 수신확인할 Gmail 계정(jyjzzjtube@gmail.com)으로 로그인
2. 크롬 웹스토어에서 **"Mailtrack"** 검색 → **Chrome에 추가**
   - 직접 링크: https://chrome.google.com/webstore → "Mailtrack for Gmail"
3. 설치 후 안내 팝업에서 **해당 Gmail 계정 연결(Connect with Google)** → 권한 허용
4. Gmail 새로고침 → 메일 작성창 하단에 **Mailtrack 체크 아이콘** 생기면 완료

## 2) 메일 보내기
- 평소처럼 작성 후 전송. 확장이 **추적 코드를 자동 삽입**함.
- (추적 끄고 싶은 메일은 작성창 하단 Mailtrack 토글을 OFF)

## 3) 수신확인 보는 법 (보낸메일함)
| 표시 | 의미 |
|---|---|
| ✓ (녹색 체크 1개) | 발송됨 — 아직 안 열어봄 |
| ✓✓ (녹색 체크 2개) | **상대가 열람함** |
- 보낸메일함에서 **체크 2개(✓✓)** 뜬 메일을 열면 → **열람 시각** 확인 가능
- 메일 안 **"See Full tracking history"** 클릭 → 전체 열람 내역(몇 번/언제) 확인

---

## ⚠️ 꼭 알아둘 점 (정직 고지)
1. **이미 보낸 6/10 메일은 소급 확인 불가.**
   Mailtrack도 "설치 후 보내는 메일"부터 추적됨. 그 메일엔 추적코드가 없어서 영영 못 봄.
   → 확인하려면 **리마인드 메일을 새로(Mailtrack 켠 상태로) 다시 발송**해야 함.
2. 상대가 **이미지 자동표시를 꺼두면** 체크 2개가 안 뜰 수 있음
   (네이버 등 일부 메일은 이미지 차단/프록시가 잦음 → 이 경우 미감지).
3. 본인이 메일을 다시 열어봐도 체크가 올라갈 수 있으니, **상대 IP/디바이스 기준은 아님**.
4. 가장 확실한 "읽음" 증거는 결국 **답장**. → 그래서 리마인드 본문(답장 유도)과 같이 쓰는 게 베스트.

## 추천 순서
1. PC 크롬에 Mailtrack 설치
2. `remind_email.txt` 내용으로 twobird89@naver.com 에 **새로 발송** (Mailtrack ON)
3. 보낸메일함에서 ✓✓ 뜨는지 + 열람 시각 확인
4. 며칠 무반응이면 한 번 더 가볍게 리마인드

> 참고: 코드로 직접 구축한 픽셀 트래커(`Code.gs`)도 같은 원리지만,
> Mailtrack은 그걸 설치형 UI로 자동화한 것. 편의성은 Mailtrack이 압도적.
