# 공간브릿지 브랜드 스토리텔링 (실적 숫자 없이 신뢰 만들기)

> 이제 막 시작하는 플랫폼. "누적 N건" 같은 숫자가 없어도 신뢰를 주는 방식 = **관점·기준·정직**을 파는 것.
> 규칙: 없는 실적 지어내기 금지. 대신 "우리가 왜 다른가"를 스토리로.

## 핵심 메시지 (한 문장)
> **"업체를 찾기 전에, 비교할 기준부터."**
> 공간브릿지는 직접 시공·판매하지 않습니다. 그래서 특정 업체 편을 들 이유가 없습니다 — 사장님 편에서 기준을 잡아드립니다.

## 신뢰의 근거를 "숫자" 대신 "구조"로
숫자가 없을 때 신뢰는 이렇게 만듭니다:
1. **이해충돌 없음** — "직접 시공 안 함"이 강점. 특정 업체를 밀 이유가 없으니 기준이 중립적
2. **정직한 고지** — 공개 시세는 "범위"로, 정부기준은 "행정용도"로 구분해 표시 (과장 안 함)
3. **무료 도구로 증명** — 말 대신 계산기·체크리스트로 "우리는 이만큼 안다"를 보여줌
4. **투명한 연결** — 파트너 연결·개인정보 동의·계약주체를 명확히

## 창업 스토리 (About 문단 초안)
```
사장님들이 인테리어·창업 준비를 하며 가장 많이 당하는 게 "견적 비교가 안 되는" 상황입니다.
업체마다 다른 양식, 빠진 항목, 계약 후 추가금.
공간브릿지는 여기서 출발했습니다.

"업체를 소개하기 전에, 비교할 기준부터 드리자."

그래서 우리는 직접 시공하지 않습니다.
대신 같은 조건표로 비교하는 법, 평당 시세 범위, 빠지면 안 되는 항목을
무료로 먼저 확인하게 하고, 조건이 맞는 파트너를 연결합니다.
최종 선택은 언제나 사장님입니다.
```

## 콘텐츠로 신뢰 쌓기 (시공 사진 없어도 되는 주제)
지금 당장 만들 수 있는 "정보형·기준형" 콘텐츠 = 시공 사진 불필요:
- "인테리어 견적서, 이 항목 빠지면 추가금" (체크리스트)
- "평당 얼마가 정상? 업종별 비용 범위"
- "업체가 말 안 해주는 것 5가지"
- "계약 전 순서: 등록→철거→시공 (부가세 환급)"
- "포스 렌탈 vs 구매, 36개월 비교"
→ 계산기·체크 도구 화면 녹화 + 자막으로 릴스/카드 제작 가능

## 프로필 4줄 (수정 — 가짜 실적 제거)
```
공간브릿지 | 상가·카페 인테리어 견적 비교
✔ 업체 찾기 전에, 비교할 기준부터 (직접 시공 X = 중립)
✔ 인테리어·포스·세무까지 필요한 분야만 연결
📩 무료 견적·기준표 → 문자 010-8443-4756 / 프로필 링크
```
- "시공실적 N건" 줄은 **넣지 않음**. 실제 실적이 쌓이면 그때 교체.

## 톤
- 과장·미사여구 없이, 사장님 언어로. "돈 아끼는 법"을 알려주는 선배 톤.
- 근거 있는 숫자는 "범위 + 출처", 없는 건 "지금 시작하는 플랫폼"이라고 솔직히.
