## 1. 원리 4개 → 인테리어 적용

### (a) [원리] 릴스=비팔로워 도달 / 카드뉴스=팔로워 → 신규 도달은 릴스

- 릴스: 시공 전후 3초 변화 → 신규 도달
- 카드뉴스: 같은 주제를 "체크리스트/비용표"로 → 팔로워 저장·정독

### (b) [원리] 프로필 4줄 = 슬로건·시공실적·가치·문의 CTA

- 링크: gongganbridge.com (프로필 링크 = 무료 계산기·상담 동선)
- ※ "시공실적" 줄은 **실제 숫자 확보 후** 교체(과장 금지) [게이트]

## 2. 세부 최적화 (현장 강점)

### 시공 전후 릴스 (주력 콘텐츠)
- 포맷: 철거/현장(3초) → 진행 컷 빠르게 → 완공(임팩트) → CTA
- 자막: 평수·업종·핵심 포인트(비용은 "범위"로, 과장 금지)
- ※ 실제 시공영상 확보 전까지는 **자료/개념 영상 + 명확한 "예시" 표기** [게이트]

### 지역 타겟
- 1차: 남양주·다산·구리·성남(현장 접근성) → 캡션·해시태그·위치태그에 지역명
- "남양주 상가 인테리어", "다산 카페 창업" 등 지역+업종

### 해시태그 (릴스 5~10 / 카드뉴스 10~15)
- 대: #상가인테리어 #카페창업 #인테리어견적
- 중: #남양주인테리어 #상가창업 #카페인테리어
- 소/롱테일: #남양주카페 #견적비교 #창업준비 #포스키오스크

### 사이트 전환 동선
릴스/카드 → 프로필 → 링크(gongganbridge.com) → **무료 계산기(유입 자석)** → 상담(문자·카톡)
- 계산기가 상담보다 먼저(디자인 헌법 준수), 상담 접수는 백오피스 CRM으로 자동 저장(구축 완료)

```
[1] 릴스 제작 (시공 전후/후킹)
     ├─ 인스타 릴스 (신규 도달)

     └─ 사이트 관련 도구/글 내부링크
```
