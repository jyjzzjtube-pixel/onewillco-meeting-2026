# 공간브릿지 무료 검색노출 세팅 가이드 (네이버·구글, 광고비 0원)

> 목표: "공간브릿지", "남양주 상가 인테리어", "카페 창업 비용" 등으로 검색하면 gongganbridge.com이 뜨게.
> 파워링크(광고) 아님. 전부 무료 오가닉 등록.

## 원리 (왜 이 순서인가)
1. **검색엔진에 "우리 사이트 여기 있다" 신고** (서치어드바이저·서치콘솔) → 안 하면 아예 안 긁어감
2. **sitemap 제출** → 우리 페이지 목록을 통째로 알려줌
3. **콘텐츠(블로그) 축적** → 네이버는 자기 블로그 글을 상위 노출. 여기서 진짜 유입이 나옴
4. **스마트플레이스** → 지역 검색(남양주 등) 노출

---

## A. 네이버 서치어드바이저 (제일 중요·10분)

1. `searchadvisor.naver.com` 접속 → 네이버 로그인
2. 우측 상단 **웹마스터 도구** → 사이트 등록에 `https://gongganbridge.com` 입력
3. **사이트 소유확인** 화면에서 "HTML 태그" 방식 선택 → 나오는
   `<meta name="naver-site-verification" content="XXXX">` 의 **XXXX 코드 복사**
4. 나(클로드코드)에게 그 코드를 주면, 사이트의 `__NAVER_VERIFICATION_CODE__`를 교체해 재배포 →
   서치어드바이저에서 **확인** 클릭
5. 확인되면: **요청 > 사이트맵 제출** 에 `sitemap.xml` 제출,
   **요청 > RSS 제출** 에 `rss.xml` 제출
6. **검증 > robots.txt** 로 수집 허용 확인

## B. 구글 서치콘솔 (5분)

1. `search.google.com/search-console` → 구글 로그인
2. 속성 추가 → **URL 접두어** 에 `https://gongganbridge.com`
3. 소유확인 "HTML 태그"의 `content` 코드 복사 → 나에게 주면 `__GOOGLE_VERIFICATION_CODE__` 교체·재배포 → 확인
4. **Sitemaps** 메뉴에 `sitemap.xml` 제출

## C. 네이버 스마트플레이스 (지역 노출·사업자 필요)

1. `smartplace.naver.com` → 로그인 → **신규 등록**
2. 업체명 "공간브릿지", 업종, 주소(사업장), 전화 입력 → 사업자 정보로 인증
3. 소개·대표 키워드에 취급 분야(인테리어·포스·세무 등) 입력
4. → "남양주 인테리어" 같은 지역 검색에 노출 시작

## D. 콘텐츠 (무료 유입의 진짜 엔진)

- `marketing/posts/` 의 글을 **네이버 블로그(blog.naver.com/bridgeone11)**에 순서대로 발행
- 각 글 맨 아래 gongganbridge.com 링크 → 블로그 유입을 사이트로
- 발행 일정은 운영 콘솔 **마케팅 탭**의 콘텐츠 캘린더로 관리 (이미 5편 등록됨)
- 제목에 **키워드(지역+업종)**를 자연스럽게: "남양주 상가 인테리어 비용" 등

## ✅ 대표가 할 일 요약
1. 네이버 서치어드바이저 등록 → 인증코드 나에게 전달 (내가 교체·재배포)
2. 구글 서치콘솔 등록 → 인증코드 전달
3. 스마트플레이스 등록(사업자 정보로)
4. 블로그에 글 발행 (내가 계속 초안 공급)
