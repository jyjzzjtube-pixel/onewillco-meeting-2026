# 포스·키오스크, 사는 게 나을까 빌리는 게 나을까

매장을 준비하면 포스와 키오스크를 두고 "렌탈이냐 구매냐" 고민합니다.
결론부터 말하면, **36개월 총비용으로 비교**해야 제대로 보입니다.

## 렌탈의 실제 비용
- 포스: 월 2~4만 원
- 키오스크: 월 6~11만 원
36개월이면 포스 72만~144만, 키오스크 216만~396만 원 수준입니다.

## 구매 vs 렌탈, 어디서 갈리나
- **구매**: 초기 목돈. 고장·업데이트·AS를 직접 부담
- **렌탈**: 초기 부담 적음. AS·교체 포함인 경우가 많음. 대신 약정 기간 확인 필수

## 계약 전 반드시 확인
- [ ] **약정 기간**과 중도 해지 위약금
- [ ] AS·고장 시 교체 포함 여부
- [ ] 카드 수수료·부가 서비스(배달 연동 등) 별도 비용
- [ ] VAT 포함 여부
