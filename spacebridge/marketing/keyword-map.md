# 8개 카테고리 한글 키워드 맵 (지역+업종, 무료 오가닉 타겟)

> 블로그 글·페이지 제목·메타에 자연스럽게 녹여 쓸 키워드. 지역은 남양주/성남/구리 등 확장.

| 분야 | 핵심 키워드 | 롱테일(질문형) |
|---|---|---|
| 인테리어·건축 | 상가 인테리어 비용, 남양주 인테리어 | "카페 인테리어 평당 얼마", "상가 인테리어 견적 비교" |
| 포스·CCTV·키오스크 | 포스 키오스크 렌탈, 매장 CCTV 설치 | "포스 렌탈 vs 구매", "키오스크 월 비용" |
| 세무기장 | 세무기장료 시세, 개인사업자 기장 | "기장료 얼마가 정상", "창업 세무 첫 달" |
| 회계관리 | 소상공인 회계, 매출 관리 | "현금흐름 관리", "사업자 결산" |
| 보험(화재보험) | 사업장 화재보험, 상가 화재보험 | "카페 화재보험 얼마", "사업장 배상책임" |
| 부동산 상담·분양 | 상가 임대, 아파트 분양 상담 | "상가 자리 보는 법", "분양 상담" |
| 홈페이지 개발 | 소상공인 홈페이지, 매장 홈페이지 제작 | "카페 홈페이지 만들기", "예약 홈페이지" |
| 앱 개발 | 매장 앱 개발, 주문 앱 제작 | "우리 가게 앱", "직원 관리 앱" |

## 규칙
- 제목 앞쪽에 키워드 배치, 억지 반복 금지(어뷰징 =네이버 저품질)
- 각 글은 하나의 핵심 키워드에 집중(1글 1주제)
- 글 하단에 gongganbridge.com 관련 도구/페이지 내부링크 1~2개
- 과장·허위 실적 금지. 수치는 "범위"로, 근거와 함께
