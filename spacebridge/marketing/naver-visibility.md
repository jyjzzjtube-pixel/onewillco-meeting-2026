# "공간브릿지" 네이버 검색 노출 — 홈+블로그+인스타+카톡 함께 뜨게

> 목표: 네이버에서 **공간브릿지** 검색 시 홈페이지·블로그·인스타·카톡채널이 브랜드로 묶여 노출.
> 원리: 네이버는 ①등록된 사이트 ②자기 블로그 글 ③서로 링크된(=같은 브랜드) 채널을 우선 노출.

## ✅ 내가 이미 적용한 것 (로그인 불필요, 커밋 완료)
1. **홈페이지 구조화데이터(sameAs)** — 블로그·인스타·카톡을 "공간브릿지 = 한 주체"로 명시. 검색엔진이 4채널을 한 브랜드로 인식.
2. **Organization/WebSite 스키마** — 상호(공간브릿지)·연락처·로고·검색박스 정의.
3. **robots(Yeti 허용)·sitemap 10개·인증 메타 슬롯** — 등록 즉시 수집되게 준비.
4. **브랜드 소개 글**(posts/00-brand-intro.md) — "공간브릿지" 검색용, 4채널 전부 링크.
5. **블로그 글 6편 전부** 하단에 4채널 상호링크 블록 삽입 — 네이버가 브랜드 연관성으로 인식.
6. 8개 카테고리 한글 키워드·지역 키워드 온페이지.

## ▶ 대표가 해야 켜지는 것 (딱 로그인 2번 + 발행)
네이버는 "등록 안 된 사이트"는 아예 안 긁습니다. 그래서 이 2개는 로그인이 필수:

1. **네이버 서치어드바이저 등록** (홈페이지 노출의 스위치)
   - searchadvisor.naver.com 로그인 → gongganbridge.com 등록 → 인증코드 나에게 → 내가 심고 재배포 → sitemap 제출
2. **블로그에 글 발행** (블로그·브랜드 노출의 엔진)
   - posts/ 의 글(00 브랜드소개부터)을 blog.naver.com/bridgeone11 에 순서대로 발행
   - 각 글이 홈·인스타·카톡을 링크 → 검색 시 브랜드로 함께 노출

3. (선택) **인스타 프로필에 gongganbridge.com 링크**, **카톡 채널 소개에 공간브릿지·홈 링크** — 상호링크 강화

## 채널별 네이버 노출 방식
| 채널 | 네이버에서 뜨는 법 | 상태 |
|---|---|---|
| 홈페이지 | 서치어드바이저 등록 → 웹문서 노출 | 준비완료, 등록만 |
| 블로그 | 글 발행 → 블로그탭 상위(네이버 강점) | 글 6편 준비, 발행만 |
| 인스타 | 브랜드명·해시태그 + 프로필 링크 | 프로필 정비 |
| 카톡채널 | 브랜드 검색 시 채널 노출 + 사이트/블로그 링크 | 링크 연결됨 |

## 핵심 한 줄
**구조·콘텐츠·상호링크는 내가 다 심었다. 네이버가 이걸 보게 하려면 "서치어드바이저 등록(로그인 1번) + 블로그 발행"만 대표가 하면 된다.** 등록 인증코드만 주면 나머지는 내가 처리.
