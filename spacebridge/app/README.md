# 공간브릿지 플랫폼

인테리어 + 포스·키오스크·CCTV·세무기장 원스톱 창업 플랫폼의 실제 작동 홈페이지입니다.
**별도 설치 없이 Node.js만 있으면 실행됩니다** (외부 패키지 0개).

## 실행 방법

```bash
node server.js
# → 홈페이지:   http://localhost:3000
# → 관리자:     http://localhost:3000/admin
```

- 기본 관리자 비밀번호: `spacebridge2026!`
- **배포 전 반드시 변경하세요:**

```bash
ADMIN_PASSWORD='나만의비밀번호' PORT=3000 node server.js
```

## 무엇이 들어있나

| 구성 | 경로 | 설명 |
|---|---|---|
| 홈페이지 | `/` | 디자인 시안 전면 적용 + 견적 폼 실동작 |
| 창업가이드 게시판 | `/guide.html` | 관리자에서 쓴 글이 노출 (카테고리 필터) |
| 관리자 | `/admin` | 대시보드 · 견적문의 DB · 게시판 CRUD |

### 견적문의 DB (디비 수집)
- 폼에서 **관심 서비스 카테고리**(인테리어 / 포스·키오스크 / CCTV·보안 / 세무기장 / 원스톱 패키지)를 복수 선택으로 수집
- 연락처·지역·평수·업종과 함께 저장
- 각 문의에 **유입 출처가 자동 귀속**됩니다 (첫 방문 시점의 채널·검색어·랜딩 페이지)
- 관리자에서 상태 관리(신규→연락중→상담완료→계약→보류), 메모, 삭제, **CSV 다운로드**

### 유입 추적 (자동)
모든 공개 페이지에서 `track.js`가 방문을 기록합니다:
- **채널 자동 판별**: 네이버 검색/블로그/카페/플레이스/광고, 구글, 인스타그램, 유튜브, 다음/카카오, 숨고, 큐플레이스, 직접 유입 등
- **검색어 추출**: 네이버(`query`)·구글(`q`) 등 검색엔진이 넘겨주는 키워드
- **UTM 파라미터** 지원: 광고·SNS 링크에 `?utm_source=instagram&utm_campaign=0월이벤트` 형태로 붙이면 캠페인별로 집계
- 개인정보는 수집하지 않음 (무작위 기기 ID만 사용)

### 대시보드
- 오늘 방문 / 기간 방문 / 순방문자 / 견적문의 / 전환율
- 일별 방문·문의 추이 (라인 차트), 유입 채널 (바 차트), 문의 카테고리 (도넛)
- 검색어 TOP 15 / 유입 도메인 TOP 10 / 인기 페이지
- 기간 필터: 7 / 14 / 30 / 90일

## 데이터 저장

`data/` 폴더에 JSON 파일로 저장됩니다 (DB 설치 불필요):
- `leads.json` — 견적문의
- `posts.json` — 게시글
- `visits-YYYY-MM.jsonl` — 방문 로그 (월별)
- `sessions.json` — 관리자 로그인 세션

**백업 = `data/` 폴더 복사.** 서버 이전 시에도 이 폴더만 옮기면 됩니다.

## 배포 안내

1. **호스팅**: Node.js를 지원하는 어디든 가능 — 가비아/카페24 Node 호스팅, AWS Lightsail, Vultr, 라즈베리파이 등. `node server.js` 하나만 실행하면 됩니다. (프로세스 유지: `pm2 start server.js` 권장)
2. **도메인 + HTTPS**: 실서비스에서는 도메인을 연결하고 HTTPS를 적용하세요 (Caddy/nginx + Let's Encrypt, 또는 Cloudflare 프록시가 가장 간단).
3. **오픈 당일 할 일**: 네이버 서치어드바이저·구글 서치콘솔 등록, 스마트플레이스에 홈페이지 링크 연결.
4. **콘텐츠 값 교체**: `public/index.html`의 `○○` 자리표시(시공 건수, 전화번호, 사업자번호, 포트폴리오 실사진)를 실제 값으로 교체하세요. 카카오톡 채널 링크는 `href="#"`로 되어 있으니 실제 채널 URL로 바꾸세요.

## 보안 메모
- 관리자 비밀번호는 환경변수로만 관리하고, 기본값을 그대로 쓰지 마세요.
- 이 서버는 소상공인 규모의 트래픽을 전제로 한 경량 구조입니다. 문의가 월 수천 건 규모로 커지면 DB(PostgreSQL 등) 이전을 권장합니다 — `data/` JSON이 그대로 마이그레이션 소스가 됩니다.
