# 공간브릿지 서비스 이미지 프롬프트 팩 v2 (챗지피티용)

사용법: ①번 공통 규칙을 먼저 붙여넣고, 이어서 각 분야 프롬프트를 하나씩 실행.
기존 이미지를 업로드하며 "이 톤을 유지하되 아래대로 재생성"이라고 하면 톤 일관성이 좋아짐.

---

## ⓪-A 최우선: 메인 히어로 리메이크 (현재 히어로 이미지를 챗지피티에 업로드하면서 실행)

> 문제: 폰 화면 속 외국인 인물 사진, 영어로 된 서류·도면 라벨, 전경 흐릿함 — 신뢰를 깎는 3요소

```
[현재 히어로 이미지 업로드 후]
이 사진을 레퍼런스로, 같은 구도(테이블 위 도면·서류·원단 샘플, 오른쪽에서 서류와 폰을 든 두 손)와
같은 따뜻한 자연광을 유지하면서 초실사로 재생성해줘. 반드시 고칠 것 6가지:

1. 스마트폰 화면: 지금의 외국인 인물 사진을 삭제하고, 밝은 화이트 배경의 "비교 체크리스트 앱 화면"으로 교체
   — 파란 체크마크가 붙은 카드 3개가 세로로 정렬된 깔끔한 UI. 글자는 판독 불가능한 추상 블록으로 (실제 문자 금지)
2. 오른손의 서류: 지금의 영어 표를 "견적 비교표" 느낌으로 교체 — 행과 열, 숫자만 보이고
   문자 라벨은 전부 흐릿한 추상 블록. 영어 단어가 한 글자도 판독되면 안 됨
3. 배경 도면: 치수 숫자와 영문 라벨 제거, 벽선·가구 배치선만 남긴 깨끗한 평면도로
4. 선명도: 전경(폰, 서류, 두 손, 원단 샘플)은 초점이 또렷하게, 나무 테이블 결과 원단 질감이 살아있게.
   배경만 얕은 심도로 흐림
5. 인물: 얼굴은 어디에도 없게. 손은 자연스러운 동아시아인(한국인) 피부톤 — 외국인 손·인물 절대 금지.
   폰·서류·도면 등 화면에 글자가 보이면 한글 느낌으로만, 영어·외국어 문자는 한 글자도 없게
6. 색감: 화이트+밝은 우드 베이스, 차분한 블루그레이 포인트(파란 웹사이트 테마와 조화). 16:9, 최고 해상도

완성 후 스스로 검수: 판독 가능한 글자 0개, 얼굴 0개, 전경 선명도, 위 6개 항목 전부 반영 여부를 확인하고
하나라도 어긋나면 다시 생성해줘.
```

## ⓪-B 홈 구조 수정 지시 (코덱스에 붙여넣기 — 이미지와 별개의 배치 문제)

> 문제: "필요한 분야를 고르면…" 밴드와 "필요한 단계나 분야로 바로 이동하세요" 밴드가 **같은 이미지 카드 세트를 중복 사용** — 스크롤 시 같은 화면이 두 번 나오는 느낌

```
홈페이지에서 카테고리 카드 세트가 두 밴드에 중복 노출되고 있다. 다음과 같이 역할을 분리해줘:
1. 상단 "필요한 분야를 고르면, 확인할 기준이 바로 보입니다" 밴드: 사진 카드 유지.
   단, 이미지가 준비되는 대로 v2 실사 이미지(service-*-v2.webp)로 교체
2. 하단 "필요한 단계나 분야로 바로 이동하세요" 밴드: 사진을 전부 제거하고
   단색 선형 아이콘 + 텍스트 링크 리스트(2열)로 단순화 — 시각 중복 제거와 스크롤 길이 축소가 목적
3. 두 밴드의 목적 문구도 구분: 상단 = "분야별 확인 기준 보기", 하단 = "바로가기"
```

## ⓪-C 상담폼 "연락받기 좋은 시간" 개선 지시 (코덱스에 붙여넣기)

> 문제: 오전/오후/저녁/주말 4칩은 실제 통화 약속을 못 잡음 — 희망 날짜+시간대가 연결률을 올림

```
상담폼의 "연락받기 좋은 시간" 칩(오전/오후/저녁/주말)을 다음으로 교체해줘:
1. [희망 날짜] 선택: 오늘부터 14일 이내 날짜 선택 (기본값 없음, 선택사항 라벨 유지)
2. [희망 시간대] 선택: 10~12시 / 12~14시 / 14~16시 / 16~18시 / 18~20시 / 아무 때나
3. 두 필드 모두 선택사항(필수 아님) — 필수 질문 4개 상한을 지키기 위함
4. 접수 문자(SMS) 본문에 선택된 날짜·시간대가 포함되게: 예 "[희망시간] 7/22 14~16시"
5. 모바일에서 날짜는 네이티브 date input, 시간대는 칩 버튼 유지 (타이핑 최소화)
```

## ⓪-D "비용 근거" 밴드 전면 교체 지시 (코덱스에 붙여넣기)

> 문제: "가맹 정보공개서 표본", "2026 과밀부담금 산정 기준 239만2천원/㎡", "월비" — 행정 용어라
> 타깃(예비 창업자·자영업자)이 이해 불가. 특히 과밀부담금은 서울 대형건축물 부담금 기준이라
> 소상공인 창업 비용과 무관 — 오해 유발로 삭제 대상. 이미지도 내용과 불일치.

```
"비용은 숫자보다, 숫자의 출처를 먼저 봅니다" 밴드의 카드 4개를 아래로 전면 교체해줘.
원칙: 고객이 쓰는 말로, 카드 제목만 읽어도 무슨 돈인지 알게. 행정 용어 금지.

카드1 [인테리어] "상가 인테리어, 평당 얼마가 평균일까?"
  수치: 평당 150~250만원 (업종별 상이) / 설명: 철거·자재·확장 여부로 달라지는 범위입니다
  버튼: 내 평수로 계산 → /calc.html?tool=cost / 이미지: 도면+자재 샘플 실사

카드2 [장비] "포스·키오스크는 사는 게 아니라 빌리는 게 기본"
  수치: 포스 월 2~4만원 · 키오스크 월 6~11만원 / 설명: 36개월 총비용으로 비교해야 정확합니다
  버튼: 렌탈 vs 구매 비교 글 → 해당 게시글 / 이미지: 카운터 위 포스+키오스크 실사

카드3 [세무] "세무기장, 시세는 정해져 있습니다"
  수치: 개인사업자 월 8~15만원 / 설명: 이보다 크게 비싸거나 싸면 이유를 물어보세요
  버튼: 세무 첫 달 가이드 → 해당 게시글 / 이미지: 계산기+영수증 뭉치 실사

카드4 [비교] "견적은 같은 조건표로 받아야 비교가 됩니다"
  수치 대신 문구: 포함·제외 항목이 다르면 싼 견적이 더 비싸집니다
  버튼: 무료 견적 진단 → /calc.html?tool=check / 이미지: 나란히 놓인 견적서 두 장 실사

삭제: 과밀부담금 카드(타깃 무관·오해 유발), "월비" 표현 전체.
이동: 가맹 정보공개서 표본은 홈에서 빼고 "프랜차이즈 준비" 별도 글로만 유지.
하단 고지 문구는 유지하되 한 문장으로 축약: "공개 범위는 참고용이며, 실제 금액은 같은 조건의 서면 견적으로 확인하세요."
```

## ① 공통 규칙 (맨 먼저 붙여넣기)

```
지금부터 만드는 이미지 8장은 한 세트다. 전부 아래 규칙을 따른다:
- 초실사 사진 스타일 (photorealistic, 일러스트 금지), 밝은 자연광이 큰 창에서 들어오는 한국의 소규모 사업장/사무 공간
- 색 톤: 밝은 화이트+우드 베이스에 차분한 블루그레이 포인트 (채도 낮게, 웹사이트 블루 테마와 조화)
- 구도: 핵심 사물을 전경에 크게, 배경은 얕은 심도로 흐림. 표면 질감(나무결, 종이, 금속)이 살아있게
- 사람: 얼굴 금지. 손·팔만 부분 등장 가능 (작업하는 손) — 반드시 동아시아인(한국인) 피부톤. 외국인 인물·손 금지
- 배경/한국 기준: 콘센트·창틀·가구·간판 등 공간 요소는 한국 실내 기준으로. 서양식 인테리어 디테일 금지
- 화면·문서 속 텍스트: 핸드폰·TV·모니터·서류·도면에 글자가 보이면 반드시 한글 느낌으로만. 영어·외국어 문자 절대 금지 (판독 가능하면 안 되고, 흐릿한 추상 블록도 라틴 알파벳 형태 금지 — 한글 자모 형태의 추상 블록으로)
- 글자·로고·브랜드·간판 문구 절대 금지 (화면·서류는 흐릿한 추상 처리)
- 비율 16:9, 최고 해상도
- 각 이미지에는 내가 지정하는 7~10개 요소가 전부 식별 가능하게 들어가야 함. 생성 후 요소 목록과 대조해서 빠진 게 있으면 다시 만들 것
```

## ② 분야별 프롬프트 (8장)

### 1. 인테리어
```
상가 인테리어 착공 직전의 현장 테이블 장면. 다음 10개 요소가 모두 보이게:
①펼쳐진 건축 도면(치수선 흐릿하게) ②노란 안전모 ③접이식 줄자 ④목재·타일 자재 샘플칩 5~6장
⑤페인트 컬러 스와치 부채꼴 ⑥태블릿에 3D 인테리어 렌더링(흐릿) ⑦수평계
⑧연필과 마스킹테이프 ⑨미니 공간 모형(폼보드) ⑩배경에 공사중인 빈 상가(비닐 커버, 사다리 흐릿)
분위기: 공사 시작 전의 설레는 준비. 전경은 도면과 자재 샘플에 초점.
```

### 2. 포스·CCTV·키오스크
```
카페 카운터의 매장 운영 장비 셋업 장면. 다음 9개 요소가 모두 보이게:
①터치스크린 POS 단말기(화면은 추상 UI) ②카드 리더기 ③영수증 프린터에서 나오는 영수증
④셀프주문 키오스크 스탠드(측면) ⑤천장 모서리의 돔형 CCTV 카메라 ⑥바코드 스캐너
⑦현금 서랍 살짝 열림 ⑧태블릿 주문 화면 ⑨배경에 흐릿한 카페 진열대와 에스프레소 머신
분위기: 오픈 준비 완료된 매장의 카운터. 전경은 POS와 카드리더에 초점.
```

### 3. 세무기장
```
세무 업무 중인 책상 장면. 다음 9개 요소가 모두 보이게:
①전자계산기(큰 버튼) ②영수증·세금계산서 뭉치(집게로 정리) ③노트북 화면에 회계 그래프(추상)
④서류 바인더 3권 세로로 ⑤인주와 도장 ⑥마감일에 동그라미 쳐진 탁상 달력(숫자만)
⑦클립·집게 트레이 ⑧안경 ⑨김이 나는 커피잔, 배경에 흐릿한 서류 캐비닛
분위기: 꼼꼼하고 신뢰감 있는 세무사 사무실. 전경은 계산기와 영수증 뭉치에 초점.
```

### 4. 회계관리
```
경영 리포트를 보는 사무 책상 장면. 세무기장과 구분되도록 디지털 대시보드 중심. 8개 요소:
①큰 모니터에 매출 차트 대시보드(추상 그래프, 글자 없음) ②출력된 막대그래프 리포트 종이
③형광펜으로 밑줄 치는 손 ④노트북 서브 화면 ⑤계산기 ⑥문서 정리 트레이
⑦접힌 안경 ⑧배경에 흐릿한 화이트보드(추상 곡선 그래프)
분위기: 숫자로 경영을 읽는 관리 사무실. 전경은 모니터 대시보드와 리포트 종이에 초점.
```

### 5. 보험 (화재보험 중심)
```
매장 화재안전 점검과 보험 가입 장면. 다음 9개 요소가 모두 보이게:
①빨간 소화기(전경) ②천장 화재감지기 ③스프링클러 헤드 ④점검 체크리스트 클립보드에 체크하는 손
⑤보험 증권 느낌의 서류 묶음과 만년필 ⑥작은 집/상가 모형을 감싸는 손 제스처
⑦소화전 표시 없는 빨간 비상함(문구 없음) ⑧안전모 ⑨배경에 흐릿한 매장 내부
분위기: 사고 전에 대비하는 안심. 전경은 소화기와 체크리스트에 초점.
```

### 6. 부동산·분양
```
상가·주택 계약 상담 테이블 장면. 다음 9개 요소가 모두 보이게:
①건물 미니어처 모형(상가+주거 복합) ②열쇠 꾸러미(새 열쇠 2~3개) ③계약서 서류와 서명하는 손(글자는 흐릿)
④평면도 도면 ⑤지역 지도(추상, 글자 없음) ⑥도장과 인주 ⑦계산기
⑧돋보기 ⑨배경 창밖으로 흐릿한 상가 건물 거리
분위기: 신중하지만 설레는 계약 순간. 전경은 건물 모형과 열쇠에 초점.
```

### 7. 홈페이지 개발
```
웹사이트 디자인 작업 데스크 장면. 다음 9개 요소가 모두 보이게:
```
