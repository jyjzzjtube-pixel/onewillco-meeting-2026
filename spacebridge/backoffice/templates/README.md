# 협력업체 용역계약서 양식 — 포맷별 안내

건별 업무 위탁(용역) 계약서. 직접 입력·인쇄·저장이 다 됩니다.

| 원하는 것 | 파일/방법 |
|---|---|
| **직접 입력 + 인쇄 + PDF 저장** | 백오피스 `/contract` 페이지에서 빈칸 채우고 "인쇄/PDF 저장" (브라우저 인쇄 → PDF). CRM 상담건에서 접수번호·분야·지역·업체명 자동 채움 지원 |
| **워드(.docx) 편집** | `용역계약서.docx` — MS Word에서 편집 |
| **한글(HWP) 편집** | `용역계약서.docx`를 **한글에서 바로 열기** (한글이 .docx 지원). 한글에서 편집 후 .hwp로 저장 |
| **엑셀(정산 표)** | 계약서는 문서형이라 엑셀 대상 아님. 정산 내역은 운영 콘솔 → 정산 원장 → **세무용 CSV**(엑셀에서 열림)로 별도 제공 |
| **인쇄** | `/contract` 인쇄 버튼(A4) 또는 .docx 인쇄 |

## 자동 채움 (CRM 연동)
`/contract?receipt=SB-20260721-001&field=인테리어&region=남양주 다산&company=가나인테리어`
→ 해당 값이 미리 채워진 상태로 열림. 운영 콘솔 정산 탭의 "용역계약서 양식" 버튼과 연결.
